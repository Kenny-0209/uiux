# 분류 관리 도구

이 폴더는 사이트의 세부 분류와 검색 태그 데이터를 다시 생성하기 위한 도구를 담습니다. 예시나 원본 코드를 변경하지 않고 분류 데이터를 별도로 관리하기 위해 만들었습니다.

`build_taxonomy.py`는 사이트의 예시 목록에 포함된 항목명, 영문명, 기존 태그와 원본 파일명을 읽어 `taxonomy.json`을 생성합니다. 여러 분류가 어울리는 항목은 복수로 연결하며, 규칙에 일치하지 않는 항목은 검토 대상으로 표시합니다. 단어 기반 분류이므로 원문의 의도와 모든 사용 사례를 개별 검증한 것은 아니며, 예시나 규칙을 바꿀 때 결과를 함께 검토해야 합니다.

사이트 루트에서 `python tools/build_taxonomy.py`를 실행할 수 있습니다. 원본 예시 목록은 `examples/`에 있으며 출처와 라이선스는 각 예시의 표시와 관련 설명을 확인하세요.
