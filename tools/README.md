# 분류 관리 도구

이 폴더는 사이트의 세부 분류와 검색 태그 데이터를 다시 생성하기 위한 도구를 담습니다. 예시나 원본 코드를 변경하지 않고 분류 데이터를 별도로 관리하기 위해 만들었습니다.

`build_taxonomy.py`는 사이트의 예시 목록에 포함된 항목명, 영문명, 설명, 기존 태그와 원본 파일명을 읽어 `taxonomy.json`을 생성합니다. 한글·영문 제목 전체와 제목에 들어 있는 주요 단어도 태그로 연결합니다. 단독으로 의미가 없는 조사와 관사는 제외하고, 대소문자 등 중복 표기는 정규화합니다. 여러 분류가 어울리는 항목은 복수로 연결하며, 규칙에 일치하지 않는 항목은 검토 대상으로 표시합니다. 단어 기반 분류이므로 원문의 의도와 모든 사용 사례를 개별 검증한 것은 아니며, 예시나 규칙을 바꿀 때 결과를 함께 검토해야 합니다.

`import_movin.py`는 Movin 저장소의 원본 파일을 보존하고 실행에 필요한 미리보기 문서만 별도로 만듭니다. 체크아웃 경로를 인수로 전달하면 고정 커밋의 출처와 라이선스가 포함된 목록을 생성합니다. `audit_taxonomy.py`는 중복 없는 예시 ID로 태그와 세부 분류별 사례 수를 집계합니다. 보고서 경로를 인수로 전달할 수 있습니다.

`build_tag_groups.py`는 `taxonomy.json`의 모든 태그를 기능, 요소, 입력, 모션, 시각 스타일, 콘텐츠, 공간, 기술, 기기 및 예시 이름·키워드·출처로 중복 분류해 `tag-groups.json`을 생성합니다. 태그 표기만으로 의미를 판단하기 어려운 항목은 `기타·검토`로 둡니다. 사례에 없는 분위기를 추정해 붙이지 않으며, 자동 분류와 수동 규칙은 추가 검토가 필요합니다. 태그 데이터를 갱신할 때 `build_taxonomy.py` 실행 후 이 도구도 다시 실행하세요.

사이트 루트에서 `python tools/build_taxonomy.py`를 실행할 수 있습니다. 원본 예시 목록은 `examples/`에 있으며 출처와 라이선스는 각 예시의 표시와 관련 설명을 확인하세요.
