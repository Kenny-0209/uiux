# 모음 — UI·UX 인터랙션 아카이브

UI·UX 패턴과 모션을 검색하고 인터랙티브 예시와 출처를 확인하는 정적 웹사이트입니다. 데스크톱과 모바일 분류, 강좌 아카이브, 참고 원천을 제공합니다.

## 폴더 구성

- `index.html`, `real-app.js`, `real.css`, `player.css` 등: 첫 화면과 검색, 예시 패널, 자동 로드 및 조작 기능.
- `examples/`: 원본 또는 패널용으로 조정한 예시, 분류 데이터, 각 원천의 라이선스 및 출처. 자세한 내용은 `examples/README.md`와 각 예시를 확인하세요.
- `course.html`, `course.js`, `course.json`: 강좌 목록과 조사한 내용. 확인하지 못한 강의는 그 상태를 표시합니다.
- `previous.html`, `sources.json`: 이전 아카이브와 참고 원천 목록.
- `taxonomy.json`, `tools/`: 항목별 세부 분류·태그와 재생성 도구. 원본 메타데이터를 바탕으로 한 규칙 기반 분류이며 하나의 예시가 여러 분류에 포함될 수 있습니다.
- `icons/`: 아이콘과 해당 라이선스.
- `.nojekyll`: GitHub Pages가 정적 파일을 그대로 제공하도록 하는 설정.

일부 예시는 외부 원본 또는 외부 에셋을 사용하여 인터넷 연결이 필요합니다. 예시별 출처, 코드 및 에셋의 이용 조건은 각 원문과 해당 라이선스를 확인하세요.

미리보기는 화면 주변에서만 불러오고 화면에서 멀어지면 해제해 메모리를 절약합니다. 다시 돌아오면 예시가 초기 상태로 다시 로드됩니다. 3D와 고부하 예시는 기존처럼 실행 수를 제한합니다.

Movin 예시의 HTML, CSS와 JavaScript는 MIT-0 원본 파일을 보존하며, 패널에 표시하기 위한 HTML만 별도로 추가했습니다. 분류와 태그는 원본 설명을 활용한 규칙 기반 결과이므로 원문 검토가 필요합니다. `tools/audit_taxonomy.py`로 태그와 세부 분류별 사례 수를 집계할 수 있습니다.

검색창에서 이름과 태그 자동완성을 선택할 수 있습니다. 상세 검색에서는 태그 종류를 둘러보고 포함·제외, AND/OR, 태그 부분·완전 일치와 출처 조건을 조합합니다. 검색어는 공백으로 함께 찾으며 `-단어`로 제외하고 `"여러 단어"`로 묶어 검색할 수 있습니다. `tag-groups.json`은 태그의 다중 분류를 담고, `tools/build_tag_groups.py`로 갱신합니다.

각 예시의 한글·영문 제목 전체와 제목 속 주요 단어는 태그에도 연결되어 있습니다. 같은 태그는 표기를 정규화해 중복을 줄이며 관사·조사처럼 단독 의미가 없는 단어는 제외합니다.

기기 필터의 `공통`은 데스크톱과 모바일 양쪽으로 분류된 예시와 기기를 따로 구분하지 않은 예시를 함께 보여 줍니다. 공통 예시는 양쪽 필터에서 찾을 수 있지만 기기별 조작 방식이 같다는 뜻은 아닙니다. 단일 기기에 분류된 예시는 해당 기기의 필터에서만 표시합니다.

공통 Show me와 Slow motion은 실행 방식이 확인된 로컬 예시에 연결됩니다. GL Transitions는 셰이더 진행률을 0.25배로, 지정된 다시 재생 예시는 타이머와 CSS 애니메이션을 느리게 적용합니다. 타이머 예시는 속도를 바꾸면 처음부터 재생합니다. 기기 또는 브라우저에서 지원하지 않거나 원본 동작을 확인할 수 없는 조작은 비활성 상태로 표시합니다.
