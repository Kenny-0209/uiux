# 근거 그림

이 폴더는 논문의 실제 그림을 도식 해설의 근거로 보여주기 위해 만들었다. 원본의 출처와 이용 조건, 표시한 변경을 기록한다. PLOS 그림 세 개는 원본 다운로드 이미지를 축소 표시하고, SfM 그림은 논문 PDF에서 해당 영역을 잘라 변환했다. 각 변경 여부를 아래에 기록한다.

- `abstract.png`: Jambor HK, Bornhäuser M (2024), Ten simple rules for designing graphical abstracts, Figure 1. https://doi.org/10.1371/journal.pcbi.1011789.g001. Figure 1 캡션에 그림이 CC0라고 명시되어 있다. https://creativecommons.org/publicdomain/zero/1.0/
- `arrows.png`: Jambor HK, Bornhäuser M (2024), 같은 논문의 Figure 6. https://doi.org/10.1371/journal.pcbi.1011789.g006. 논문은 CC BY 4.0. https://creativecommons.org/licenses/by/4.0/ 출처·저자·제목·라이선스 및 변경 여부는 사이트에도 표시한다.
- `axes.png`: Rougier NP, Droettboom M, Bourne PE (2014), Ten Simple Rules for Better Figures, Figure 6. https://doi.org/10.1371/journal.pcbi.1003833.g006. 논문은 CC0. https://creativecommons.org/publicdomain/zero/1.0/

사이트의 자체 설명과 이 원본 그림은 별개이다. 예시 그림은 원저자의 맥락에서 확인하고 다른 목적으로 재사용할 때 포함된 제3자 소재의 권리와 구체적 적용 조건을 다시 확인한다.
- `sfm.png`: Xingyi He, Jiaming Sun, Yifan Wang, Sida Peng, Qixing Huang, Hujun Bao, Xiaowei Zhou, Detector-Free Structure from Motion (2023), arXiv:2306.15669v1 Figure 3, PDF 4쪽. https://arxiv.org/abs/2306.15669. 원문에 표시된 CC BY 4.0: https://creativecommons.org/licenses/by/4.0/. PDF에서 Figure 3 영역만 잘라 이미지로 변환했다. 캡션은 그림에서 분리되었으며 사이트에서 출처·변경 및 논문 원문 링크를 제공한다.
