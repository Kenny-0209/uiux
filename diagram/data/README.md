# 도식 데이터

이 폴더는 도식 백과사전의 탐색 항목을 저장한다. diagrams.json은 각 도식의 이름, 분류, 사용 목적과 문서, 설명, 선택 조건, 주의점, 대안, 예시 및 참고 원문을 보유한다. 원문 링크는 작성 근거 및 추가 탐색용이며 외부 이미지를 복제하거나 재배포하지 않는다. 문서별 도식 추천은 편집상 제안이고 모든 제출 기관의 필수 요건은 아니다. 2026-10-28 조사 내용을 바탕으로 작성했다.

`sources.json`은 2026-10-28 도식조사 문서의 링크를 제목과 당시 문서 구분별로 정리한 참고 출처 목록이다. 출처는 정기 확인이 필요하며 목록 포함이 자료의 재게시 허용을 뜻하지 않는다.
