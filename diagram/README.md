# 도식백과

보고서·연구 제안서·논문·발표자료에 쓰이는 도식과 시각화의 선택 기준을 살펴보는 정적 웹사이트다. 기존 UI·UX 아카이브의 분야 탐색·설계 지식 구조를 참고해 별도로 만들었다. `index.html`, `style.css`, `app.js`는 화면과 동작을, `visuals.js`는 자체 제작한 도식 개념 예시를, `data` 폴더는 도식과 문서별 설계 지식을 담는다. 실제 연구 결과를 표현한 그림이 아니며 모든 분야를 망라한 완결판은 아니다.
