# 실제 코드 예시

`mo01`부터 `mo12`는 Animation Handbook의 MIT 예시입니다. 각 `source.html`은 원본이고 `index.html`은 코드와 실험 동작은 유지한 채 공통 CSS/JS 경로 및 iframe 배치용 스타일만 조정한 미리보기입니다. `asset`은 원 프로젝트의 공통 CSS/JS이며 `LIC-MOT.txt`에 원본 라이선스를 보존합니다.

`ui01`부터 `ui16`은 100 Free AI UI Components의 MIT 예시이며, `index.html`은 원본 파일 그대로입니다. `LIC-UI.txt`에 원본 라이선스를 보존합니다. `manifest.json`은 항목별 이름, 출처, 소스 경로, 수정 사항을 제공합니다.


## 추가 원본 예시 · 2026-10-28

- tr01~tr09: Animation Handbook의 화면 전환 원본 HTML과 패널용 배치. camera-manifest.json에서 원본·공통 코드·MIT 라이선스를 연결합니다.
- cam01~cam03: 카메라 이동과 화각의 원본 웹사이트 연결입니다. 소스와 모델은 로컬에 복제하지 않았으며 인터넷이 필요합니다. camera-manifest.json에 출처와 사용 조건을 표시합니다.
- sp01~sp03, sp3d: three.js 원본 예시 및 관련 코드의 고정 버전과 MIT 코드 라이선스. 화면은 공식 사이트에서 실행되므로 인터넷이 필요하며 모델·환경 에셋의 조건은 코드 라이선스와 다를 수 있습니다. spatial-manifest.json을 참고하세요.
- lay01~lay02: Start Bootstrap 화면 템플릿의 원본 코드, 의존성과 라이선스. 패널용 변경 범위는 ui-more.json과 각 폴더의 README에 기록했습니다.
- 각 원본 폴더의 README는 구성과 원본·미리보기 구분을 설명합니다. 상세 조사와 검증은 ../../../2026-10-28/카메라연구.md, 3D원본.md, 레이아웃.md를 참고하세요.
