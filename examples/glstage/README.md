GL Transitions 실행 어댑터

원본 GLSL을 WebGL에서 실행하기 위한 별도 작성 코드입니다. 예제 그림은 저작권이 불명확한 원본 이미지를 사용하지 않고 브라우저에서 생성한 단순 색상 배경입니다. 어댑터와 이미지 생성 코드는 GL Transitions 원본이 아닙니다. 각 gtNN 폴더는 원본 셰이더와 작성자 및 MIT 고지를 그대로 보존합니다.

어댑터의 재생 속도는 패널의 Slow motion과 연결됩니다. 느린 모드는 진행률을 0.25배로 갱신하며, 재생 중 전환해도 현재 진행 위치에서 속도를 바꿉니다. 초기화 완료·실패 상태는 패널에 알려 공통 조작 버튼을 갱신합니다.
