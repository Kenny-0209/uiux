# 스크롤 스토리 원본

Alejandro Brito의 MIT 라이선스 Scroll Story Lab 원본 HTML을 수정하지 않고 보존합니다. 패널 안에서 스크롤하며 실제 예시를 조작할 수 있습니다. HTML 안에는 코드 설명도 포함되어 있으며 영문입니다. CSS 스크롤 타임라인은 브라우저 지원에 따라 원본의 대체 화면이 표시될 수 있습니다.
