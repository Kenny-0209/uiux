# Magic CSS 등장과 퇴장 효과

miniMAC/magic의 MIT 라이선스 원본 `magic.css`와 `LICENSE.txt`, 원본 README를 보존합니다. 각 패널의 HTML은 원본 라이브러리 효과를 버튼으로 실행하고 반복해 비교할 수 있도록 구성한 별도 인터페이스입니다. 마법 효과의 종류는 원본 CSS의 서로 다른 클래스이며 순방향·역방향은 별도로 명시합니다. 동일 효과의 좌우 방향만 바꾼 복제는 수집하지 않았습니다.

아이콘은 원본 Magic 공식 데모가 사용하는 Ionicons의 `ios-rocket` SVG이며 별도의 MIT 라이선스 `ION-LIC.txt`를 보존합니다.
