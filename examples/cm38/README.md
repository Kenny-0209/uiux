# 키보드 카메라 이동

이 폴더는 Yomotsu camera-controls의 카메라 조작 예제 `keyboard`를 보존하기 위해 만들었습니다. `source.html`은 고정 커밋 `c51601107e266097edf6a9caa57bfa9eaa77427c`의 원본이며 출처는 https://github.com/yomotsu/camera-controls/blob/c51601107e266097edf6a9caa57bfa9eaa77427c/examples/keyboard.html 입니다.

실행은 공식 원본 https://yomotsu.github.io/camera-controls/examples/keyboard.html 를 연결하며 네트워크와 WebGL 호환 기기가 필요합니다. 원격 버전은 보관된 코드와 다를 수 있습니다. MIT 고지는 `../LIC-YMT.txt`를 참고하세요. 의존 라이브러리와 외부 자산 조건은 별도로 확인해야 합니다.
