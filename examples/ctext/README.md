# Colorion 텍스트 효과

Colorion의 실제 효과별 HTML 마크업과 CSS 스니펫을 `effect-data.json`에서 분리해 수록한 예시입니다. 원본 자료는 https://text-effects.colorion.co/ 및 https://github.com/ckissi/colorion-text-effects 에서 확인할 수 있습니다. 원본 사이트와 저장소 설명은 효과 코드가 MIT 라이선스라고 명시하지만 별도 LICENSE 파일을 제공하지 않아 이 사실과 표준 MIT 조건을 LICENSE.txt에 기록했습니다.

각 HTML은 원본 마크업과 CSS를 그대로 삽입하고 재생·정지 및 색상 변경 컨트롤만 추가한 패널입니다. 자동 실행 부담을 줄이기 위해 처음에는 일시 정지합니다. 패널의 재생 버튼을 누르면 효과를 볼 수 있습니다. 각 CSS 파일의 주석에는 원본 마크업이 보존됩니다. 2026-10-28에 수집했습니다.
