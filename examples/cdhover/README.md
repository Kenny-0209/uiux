# Codrops 버튼 호버

MIT 라이선스의 Codrops ButtonHoverStyles 원본 `source.html`, `css/base.css`, `LICENSE.txt`를 보존합니다. 각 패널 HTML은 원본의 해당 버튼을 추출하여 화면 중앙에 배치한 것입니다. `css/interactive.css`는 원본 CSS의 호버 선택자에 토글 클래스를 추가하여 터치 환경에서도 효과를 확인할 수 있도록 한 파생본입니다. 외부 광고·트래킹·폰트는 제거했습니다.

원본: https://github.com/codrops/ButtonHoverStyles
