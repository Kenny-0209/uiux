# 원근 투영의 두 카메라 시야

카메라 개념 예시를 보존하기 위해 만든 폴더입니다. 원본 https://github.com/mrdoob/three.js/blob/823ede35cb0213937b55430ceb403d769c36971d/manual/examples/cameras-perspective-2-scenes.html의 고정 커밋 HTML을 `source.html`에 보관했습니다. 실행은 https://threejs.org/manual/examples/cameras-perspective-2-scenes.html 에서 제공되는 원본을 연결하므로 인터넷과 호환 환경이 필요하며 원격 화면은 저장된 소스와 달라질 수 있습니다. 코드 라이선스는 `./examples/sp3d/LICENSE.txt`이며 모델·이미지·라이브러리는 별도 조건을 확인해야 합니다.
