# three.js 공통 원본

공식 three.js 저장소에서 2026-10-28에 확인한 고정 커밋의 MIT 라이선스 원문과 오빗·변환 도구, glTF·SVG·HDR 로더 원본을 보관합니다. 각 파일은 원문 그대로이며, `sp01`~`sp03`이 사용하는 코드의 출처와 실행 맥락을 확인하기 위해 마련했습니다. `LICENSE.txt`에 저작권과 사용 조건이 있습니다.

원격 원본 페이지는 three.js 사이트의 라이브 버전을 사용하며 이 보관본과 시점 차이가 날 수 있습니다. 모델·이미지·SVG 등 에셋은 이 폴더에 복사하지 않았고 원본 사이트가 직접 불러옵니다. 예시 폴더 README와 매니페스트의 링크를 참고하세요.
