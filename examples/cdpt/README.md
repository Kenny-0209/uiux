# Codrops 화면 전환

Codrops PageTransitions 원본의 고정 리비전 `d608c934d683cab9558608409a912ef864bba2e8`을 기반으로 수집한 인터랙티브 전환입니다. `source.html`, `css/`, `js/`, `fonts/`는 원본이며, `index.html`은 선택된 전환을 갤러리 패널에서 단일 버튼으로 반복할 수 있도록 구성한 미리보기입니다. 실제 CSS 전환 클래스와 원본 JavaScript를 사용합니다. 복제한 효과의 방향만 다른 변형은 전부 별개 항목으로 취급하지 않습니다.
