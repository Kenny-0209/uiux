# three.js 공식 3D 예제

원본 저장소의 823ede35cb0213937b55430ceb403d769c36971d 리비전에서 예제 HTML을 보존합니다. 3D 형상, 객체 선택, 조명, 애니메이션, 모델 형식과 재질 등 서로 다른 실제 예제를 담았습니다. 패널은 원본 사이트의 라이브 예제를 연결하므로 인터넷과 WebGL이 필요하고 라이브 버전은 보관된 코드와 다를 수 있습니다. 원본 LICENSE를 보존하며 외부 모델·텍스처 자산은 이 폴더에 복사하지 않았습니다. GPU 사용은 사이트에서 사용자가 예제를 시작할 때 한 개로 제한합니다.
