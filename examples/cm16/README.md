# 카메라 경로 기록과 재생

원본: https://github.com/nytimes/three-story-controls/blob/f839ff3c87302e6e56af221949dbe5c64f4d1a39/examples/demos/camera-helper/index.html

`source.html`과 `script.js`는 고정 커밋의 원본이며 Apache-2.0 코드 고지는 `../LIC-NYT.txt`입니다. `index.html`은 원본이 이용한 Skypack three@0.137.0 CDN이 500 오류를 반환해 native importmap과 동일 버전의 jsDelivr three 및 gsap CDN으로 교체한 실행용 파일입니다. 공유 원본 `../nytlib/controls.js`와 아이콘 경로도 로컬로 연결합니다. JavaScript 예제 동작은 원본 그대로이며 네트워크, WebGL 지원이 필요합니다. 외부 라이브러리와 자산은 별도 이용 조건을 확인하세요.
