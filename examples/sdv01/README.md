# 캐러셀 위치 표시와 스크롤

Bramus의 Scroll-driven Animations 원본 예제 https://scroll-driven-animations.style/demos/carousel-with-markers/css/를 2026-10-28에 읽어 HTML과 예제별 CSS를 보존했습니다. 미리보기는 원본 페이지 iframe을 사용하므로 인터넷 연결이 필요합니다. 원본 사이트는 코드에 Apache License 2.0을 명시합니다: https://scroll-driven-animations.style/. 외부 이미지·폰트·polyfill은 복사하지 않았으며 개별 조건을 확인해야 합니다. 사이트가 갱신되면 미리보기와 보존된 소스가 달라질 수 있습니다.
