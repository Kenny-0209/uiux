# 오빗 카메라 조작

three.js 공식 예제의 카메라 조작을 보여주기 위해 만든 폴더입니다. `source.html`은 고정 커밋 `823ede35cb0213937b55430ceb403d769c36971d`의 HTML 원본입니다. 원본: https://github.com/mrdoob/three.js/blob/823ede35cb0213937b55430ceb403d769c36971d/examples/misc_controls_orbit.html

실시간 예시는 공식 https://threejs.org/examples/misc_controls_orbit.html 를 그대로 불러오므로 인터넷과 WebGL 지원이 필요하며, 공개 사이트의 버전이 원본 저장 시점과 달라질 수 있습니다. 카메라·모델·텍스처·외부 자산은 공식 사이트에서 로드하며 별도 이용 조건을 확인해야 합니다. 공통 MIT 코드 라이선스는 `../sp3d/LICENSE.txt`입니다.
