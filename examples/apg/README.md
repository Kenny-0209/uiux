# WAI-ARIA APG 예시

W3C의 WAI-ARIA Authoring Practices Guide 공식 예시를 원본 커밋에서 가져온 자료다. 각 apNN 폴더는 원본 HTML, 원본 CSS·JavaScript 및 패널용 HTML을 담는다. 패널은 원본의 Example 부분만 추출하여 표시한다. 원본 파일과 라이선스 및 링크는 별도로 보존한다. 원본 예시는 영어이며 공식 사이트에는 키보드 사용법과 주의사항이 있다.
